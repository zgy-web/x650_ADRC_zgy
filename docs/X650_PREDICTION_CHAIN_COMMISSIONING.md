# X650 两条预测链的修复与验收

本阶段承接 2026-10-22 首次 MPC 末端保持失败。开发记录为
`runs/x650_wholebody_mpc_v1_20261022_124705_8436`；它不能作为新版本的独立验收记录。
所有实际飞行在既有服务器 PX4／Gazebo 平台执行，使用 X650 URDF 和原二连杆。

## 开发证据及修改范围

原关节模型假设新速度指令立即执行，但物理日志显示：每步关节位置差与该物理步实际速度的积分一致至约 `1.6e-15 rad`；能匹配的新速度变化比控制器消费状态晚约 20–28 ms。关节反馈在自身 header 时刻与物理位置一致，但控制消费时已旧 0–20 ms。这支持带通信／计算时序的速度执行模型，不能据此声称辨识出了真实电机惯性。

新的关节链以实际 q、dq、JointState header 和控制消费时刻为初值，用历史已发送指令分段传播，显式计入在途指令。候选消费至速度作用时间为 24 ms；保护时间在正式实验前设为 50 ms，与已有控制周期上限一致，覆盖观测到的 28 ms 及新增计算／记录开销。二者是工程近似，不是任意服务器负载下的硬实时保证。共同速度、指令变化率、关节位置限制保持原值，并对执行前可能继续运动的区间保留余量。

原姿态预测只外推当前角速度，与未来水平输入无关。新链保留已验收的水平二阶速度响应，由预测加速度得到推力方向，再计算姿态和 `p_tip = p_base + R r(q)`。当前实测姿态的残差连续绑定到初值并衰减，末端位置和速度成本包含姿态对控制输入的导数。这是上层预测模型扩展，不是完整刚体／机械臂力矩 NMPC。

已验收基体参数、PX4 PID、物理模型、定位配置、15 节点／0.04 s 预测设置和成本权重保持不变。新增协议名为 `mixed_response_prediction_chain_v2`；它与旧协议共享 `precision_ev_mixed_mpc_v3` 物理及反馈条件，算法协议 SHA 单独区分。旧 `mixed_response_zero_ff_v1` 的内容和 SHA 保留。

## 求解与启动时序

新链的正定二次问题先求 Cholesky 无约束最优点。仅当它位于全部线性约束和输入上下限内部、且留有至少 `1e-10` 裕量时直接采用；否则仍调用原 SLSQP。两条路径都经过同样的 primal/KKT 检查和 20 ms 优化预算审计，分别记录真实求解方法与迭代次数。此项优化不改变目标、预测节点、允许的解或失败门槛。

控制交接必须等到一条新的保持指令在两关节和 PVA 三个本地发布接口均正常返回后才激活。任务起点取这条真实指令的仿真时间，保留原 `last` 和 `next_control`；首步 dt 来自实际相邻指令时间。仅刷新回调或推进 `/clock` 不构成成功交接。PID 与 MPC 使用同一交接入口。

交接关键路径不再同步保存大份元数据或刷新终端输出；已有启动证据保留，激活历史先在内存中保存，再由完成、异常和最终归档流程写入。真实控制间隔超过 50 ms 仍立即触发保护，不通过重置 dt 掩盖间隔。`solve_ms`、分配器 `compute_ms`、控制记录的计算／发送跨度和相邻指令间隔分别报告，不能互相替代。

## 起飞前冻结和新的完整验收

1. 保存开发分析的原始文件哈希、候选算法源码及任务协议。先检查分段传播、姿态输出导数、共同约束和异常恢复记录。异常快照必须保留失败步骤完整初值与上一条已发送指令。
2. 新运行一次相同协议的 PID 末端保持，取得该协议下的匹配基线；旧 PID 证书不能解锁新版 MPC。
3. 新运行完整 30 s MPC 末端保持，独立核对原生物理数据、实际下发命令、PX4 ULog、反馈、参数、着陆和参数恢复。失败保留原记录，不能裁取成功片段或更改门槛补发证书。
4. 本次仍使用原冻结门槛：末端三维 RMS ≤ 5 cm、峰值 ≤ 10 cm、倾角 ≤ 8°，所有 MPC 解满足原始数值质量要求且优化耗时 ≤ 20 ms，无前一计划回退。报告实际毫米级误差，不能将“过门槛”等同“优于 PID”。额外检查整段实际关节软位置边界及发送指令变化率。

新完整实验用于验收该控制实现的端到端表现。小幅保持中的关节运动若不足以激励执行链，不能声称全关节范围、近限位刹停或强扰动已经验证。正式八字和全身 NMPC 仍须后续逐级完成。
