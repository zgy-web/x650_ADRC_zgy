# X650 MPC：规划与最终候选的关节安全余量

2026-10-26 检查确认，原 TS20 MPC 的 QP 预测节点允许到达原关节角度和速度边界，最终完整非线性候选检查却额外预留 `0.0003 rad` 和 `0.03 rad/s`。本次已将相同余量加入 C++ 与 Python 的预测状态约束。**这项实现差异已修正，但第 429 次固定输入回放仍被最终检查拒绝；剩余原因是两个预测节点之间的速度极值。完整受扰飞行尚未通过。**

## 一致性修正

设节点线性预测为 `q_lin`、`dq_lin`，原状态界为 `q_min/q_max`、`v_max`。本次 QP 使用：

\[
q_{\min}+0.0003\le q_i^{\mathrm{lin}}\le q_{\max}-0.0003,
\qquad
-v_{\max}+0.03\le\dot q_i^{\mathrm{lin}}\le v_{\max}-0.03.
\]

最终检查继续要求完整 TS20 传播区间的极小／极大值满足同一余量，原 `2e-7` 数值容差保持。QP 求解器内部每原行精度是另一用途的数值条件，没有用安全余量替代它。

| 预测状态 | 原节点范围 | 新节点范围 |
|---|---|---|
| q1，rad | −0.75～0.45 | **−0.7497～0.4497** |
| q2，rad | −0.35～0.85 | **−0.3497～0.8497** |
| dq1，rad/s | ±0.45 | **±0.42** |
| dq2，rad/s | ±0.35 | **±0.32** |

修改仅作用于 QP 的节点状态 `Q/D` 行。积分参考 `q_ref` 的原边界、输出指令速度及变化率、输入归一化与代价、待执行命令历史、制动预留、0.02 信赖域和 50 ms 总时限保持原值。没有直接缩小全局 `q_lower` 或 `velocity_limit`，避免将状态余量误用于指令和制动公式。

C++ 的 `native/joint_safety.hpp` 为矩阵组装与候选检查提供共同常量；Python 两处从既有 `CANDIDATE_POLICY` 读取。C ABI、Core ABI 2 与配置结构不变，但优化库的行为和 SHA 已改变，旧软件验收与旧飞行证书不能授权新库。测试库位于独立构建目录，未替换已验收的仿真运行库。

## 剩余差距：节点之间的极值

原调用时刻为任务时间 **8.604 s**。完整模型记录的 dq1 极小值位于 **9.124510458 s**，即未来约 **0.520510 s**，是相邻节点之间的加速度过零极值：

|---|---:|---:|
| 9.104，左节点 | −0.411739997368 | −0.411796617023 |
| **9.124510458，节点之间** | 此时没有 QP 节点 | **−0.420047472385** |
| 9.144，右节点 | −0.420000000000001 | −0.419388431730 |
| 9.184，最后节点 | −0.420000000000000 | −0.419532412481 |

新版全部 15 个完整模型节点均满足速度余量；节点间极值没有满足。两层使用同一余量数值，不意味着离散节点约束等价于全区间非线性包络检查。线性代理与完整模型仍有差异，但本次残余拒绝已定位为节点间极值，而不是 QP 节点越界或计算超时。

完整传播还包含关节测量源时间之后的已发送和在途动作，未来优化不能改变已存在的运动。最终检查仍必要。

## 验证范围与后续

- 新安全余量回归 15 项、既有 native 优化测试 21 项、TS20 MPC 测试 6 项，以及 CTest 2 项，共 **44 项通过**；独立审计另有 **7 项反例测试通过**。包含 C++／Python 全矩阵一致、旧边界反例、真实凸 QP、安全余量与容差边界、节点安全但区间极值拒绝，以及未改参考和指令边界。
- 原完整前缀重建 429 次，其中 428 次接受、1 次拒绝，逐次与原记录核对。
- 新版对原固定 Memory 的第 1、378、379、380、383、384、428 次调用均通过，379／383 的恢复仍成功；它们是各自独立的固定输入回放，不是新版闭环轨迹。
- 第 429 次未通过结果完整保留。没有下发候选、启动 Gazebo 飞行或注入延时。

原 q+T·dq 制动形式在 QP 与可信中心中保持；现实现只对恢复后的最终候选额外做其非线性节点复核，普通最终候选并不具备这项额外检查。本次不将该已有设计差别表述为所有前后验条件完全等价。

下一项应针对已定位的节点间极值，考虑把相应时刻加入预测约束，或在有界重新线性化中补充约束，保持原最终检查和计算预算。后续改动仍须先做固定输入与正常工况回归，再重新跑完整原波形受扰实验；本次软件结果不替代恢复精度和完整飞行验收。
