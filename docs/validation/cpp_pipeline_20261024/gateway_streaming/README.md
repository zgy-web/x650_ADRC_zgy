# 最新有效指令流的软件验收

本归档记录 `latest_value_v1` 网关的软件验收：Release CTest 6/6、真实 ROS 私有域合成反馈测试 14/14，以及完整 loopback MAVLink 编码与停止零指令消费验证通过。未启动 Gazebo/PX4，也没有真实仿真或真机飞行；完整末端保持仍须单独验收。

正常输出保留 20 ms 固定相位，允许上一条消费反馈尚未到达时发送下一条有效指令。原 50 ms 指令时效、25 ms 状态新鲜度、40 ms 实际发送间隔保护保持不变。新增的每关节 40 ms 未确认进展预算绑定原始发送时刻，不由新发送续期；它与发送间隔保护是两个不同条件。计数跳过只记录 `superseded_or_unobserved`，不补造消费回执。整组回执要求同一条实际反馈精确匹配同一发送的两个关节；停止零指令仍须真实消费后释放。

14 项包含 23/30 ms 延迟观察、计数跳变、混合关节批次、重复及旧观察、错误计数/数值/回退、缺少消费进展、单关节无进展、状态断流、源断流、零指令越过未观察旧命令及 SIGINT 退出。SIGINT 项只证明软件退出，不代表安全零指令释放。完整 wire 测试另确认 6 条 PVA 消息字段、4 个候选序列的真实模拟消费、7 次发送/7 次回执（含最后零指令），最大实际输出间隔 20.077223 ms。

原失败版本一并保留在 zip 中：v1 的测试错误地限制正常发送条数为两条；v2 暴露状态过期与消费进展检查的优先级问题；v3 的源断流测试同时制造了无消费进展，随后将测试输入隔离为单一故障。v4 是修正后的完整 14 项结果，未放宽任何保护阈值或预期故障原因。

`gateway_streaming_software_v1.zip` 包含最终源码、原始 ROS 消息 JSON、初始 ActuatorState CDR、消费台账、测试日志及保留的失败报告。`manifest.json` 列出服务器路径及每个原件的大小/SHA；全部 393 项已在本地逐项复验，最终 12 个编辑文件与本地 `source_freeze.json` 完全相同。服务器独立安装目录为 `/root/autodl-tmp/flyarm_gateway_streaming_20261024/install`，最终 `live_dispatcher` SHA256 为 `ee5c67b557355b11c6f344734b692adfa6c1654dbc27c31ecc3fb42d77586aa6`。

匿名 Float64 传输的计数映射仍依赖每关节独占、有序且无重复的桥接假设；本软件证明没有将该假设提升为真机已验证事实。实际消费以及独占交接还必须由后续原生物理记录独立复核。
