# X650＋二连杆机械臂：完整 C++ 快速八字验证

本次快速八字已在服务器 PX4／Gazebo 完成并通过独立物理验收。使用用户导入的 X650 URDF、原二连杆机械臂、TS20-50 条件执行器模型与精密 EV 定位。上层协同 MPC 仍同时计算三个机体平移通道与两个关节通道；底层由 PX4 和舵机模型执行。

## 工况与控制参数

世界 XZ 参考为 X±0.25 m、Z±0.10 m，**8 s/圈、2圈**。原 C2 相位律包含2 s起始保持、首末各2 s平滑加减速及4 s末尾保持，总窗口24 s，运动区间2–20 s。中心和时间原点由实际 LiveStart 确定，没有拟合位置、时间或相位。

本轮保持普通八字接受的 Core、QP、TS20预测库、全部控制权重、物理配置、关节限制和执行保护不变。新增严格 `fast_figure8` 入口及对应软件证明；C++状态源与新worker使用同一原相位律，按实际首步长构造未来各节点的目标位置、速度和加速度。普通入口仍严格校验原12 s工况。
