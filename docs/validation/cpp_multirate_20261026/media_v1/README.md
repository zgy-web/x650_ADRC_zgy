# 完整 24 秒受扰实验视频

文件：`X650_MPC25Hz_24s_disturbance.mp4`。1600 × 1140，24 fps，576 帧，24 秒，1 倍仿真时间，无音轨。

这是上一层目录所记录的同一次 PX4／Gazebo 实验的实测状态可视化。没有重新运行物理仿真，也不是 Gazebo 界面录屏或真机录像。左侧固定世界视角展示机体偏移，右侧随实际机械臂位置移动的近景展示关节运动，两侧来自同一次实验；底部为同一时刻的三维末端误差。

- 黄色为原目标轨迹及当前目标标记，蓝色为已经发生的实际末端轨迹。
- 三段施扰分别为世界 X 方向 +1.5 N（7–7.6 s）、−1.5 N（13–13.6 s），世界 Y 方向 +0.04 N·m 自由偶矩（20.5–20.9 s）。画面中的输入数值取自原物理步已入账施扰命令，不能解释为力传感器测量。
- 上层 MPC 名义 25 Hz，连续指令输出 50 Hz；原 0.42／0.32 rad/s 预测速度内界保留。
- 完整执行、关节实际消费与退出审计通过；全窗末端 RMS 为 42.358 mm，峰值为 185.172 mm（9.212 s），超过原 100 mm 门槛，因此整体精度验收未通过。
- 三次外扰后均恢复到 10 mm 内并持续至少 1 秒。恢复成功不抵消峰值超限。

视频使用原始 48.136–72.136 s 物理窗口、任务 0–24 s 的全部 6001 个有效采样来核对指标。576 帧显示源任务时刻 0 至 23.958333 s，精确 24 s 终态另存 `final_state.png`，没有追加冻结帧充作物理时段。机体位置和关节角在相邻真实采样之间线性插值，姿态用四元数 SLERP。网格与装配来源、全部采样正运动学一致性和输入 SHA 均由 `replay_manifest.json` 保存。旋翼转角未记录，保持 URDF 原始零位。

本视频只覆盖所验收的 24 秒控制窗口，不包含窗口之后的降落过程；降落、停桨、参数恢复依据上一级完整审计报告。视频生成成功不会授予新的实验或真机验收。
