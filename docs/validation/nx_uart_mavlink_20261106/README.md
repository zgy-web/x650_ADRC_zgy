## 实测

| 指标 | 修复前 | 修复后 |
|---|---:|---:|
| 窗口 | 20秒 | 20.000457秒 |
| UART接收字节 | 871 | 858 |
| 匹配方言且CRC通过的帧 | 0 | 46 |

修复后心跳来自PX4系统/组件1/1，最后一帧显示未解锁；COM13独立收尾回读也确认未解锁。收到20个HEARTBEAT、20个MISSION_CURRENT及6个CURRENT_EVENT_SEQUENCE。消息数量受采集窗口相位影响，不要求与另一次电脑接收的47帧完全相同。

NX应用串口写入次数和驱动TX增量均为0；复测物理仅连接飞控TX→NX RX及GND，不接NX TX、VCC和流控。串口设置已恢复、FD已关闭、无遗留占用，RAM诊断源码和二进制已清理，完整实验记录保存在电脑。Windows及局域网SSH在换线后恢复可用。
