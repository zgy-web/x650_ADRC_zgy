# 上层 NMPC 的数学定义与实现对应

这份定义对应 `python/x650_nmpc_standard/model.py` 与 `solver.py`。它是一个显式光滑非线性离散最优控制问题。下层仍由 PX4 及 TS20 关节驱动完成速度/姿态/电机控制；因此本控制器的准确名称是**上层协同 NMPC**，不是旋翼推力与关节力矩级的全身动力学 NMPC。

新模型不能直接继承旧原型的实验结论。其光滑关节模型、数值积分、求解结果、原事件模型候选检查与真实闭环需要分别验证。

## 1. 状态、输入与已知参数

每个预测节点的 23 维状态为

\[
x_i=\left[p_i^T,v_i^T,q_i^T,\dot q_i^T,a_{xy,i}^T,
r_i^T,F_{a,i}^T,F_{p,i}^T,u_{i-1}^T\right]^T.
\]

其中 `p,v` 是 ENU 世界系机体位置和速度，`q,dq` 是两个关节的实际角度与角速度，`a_xy` 是水平加速度；`r` 是关节驱动器的积分位置参考。`F_a,F_p` 分别保存已生效及已发送但尚未生效的两维驱动强迫项。最后五维保存上一段控制量，用于增量约束与代价。

优化输入采用物理单位：

\[
u_i=[v^c_{x,i},v^c_{y,i},v^c_{z,i},\nu_{1,i},\nu_{2,i}]^T.
\]

前三项单位为 m/s，后两项为 rad/s。`nu` 是命令速度，不能当作实际 `dq`。决策时域为 15 个节点，第一段使用原反馈的实际 `dt`，其余段为 0.04 s。已发送报文、总线原点与原始时间戳均为固定输入，优化器不能重写。

每段另有 161 个已知参数，保存步长、目标预览、名义姿态背景、总线/延迟事件时刻、首指令保护界等。**这些参数不都是优化变量**。单次控制序列有 75 个自由控制量；多重打靶还显式引入节点状态，并用动力学等式连接它们。

## 2. 非线性离散预测

采用

\[
x_{i+1}=F_{h_i}(x_i,u_i;\pi_i).
\]

水平机体通道延用已辨识的闭环二阶响应：

\[
\dot p_j=v_j,\qquad \dot v_j=a_j,\qquad
\dot a_j=\omega_{n,j}^2(v^c_j-v_j)-2\zeta_j\omega_{n,j}a_j,
\quad j\in\{x,y\}.
\]

垂直通道为 `dot(p_z)=v_z`、`dot(v_z)=(v_z^c-v_z)/tau_z`。这部分用常值输入的精确 ZOH 映射；它是下层闭环响应模型，不是忽略下层控制器的自由刚体动力学。

在两个关节上，已生效驱动强迫项给出

\[
\dot q=\omega,\qquad
J\dot\omega=F_a-K_pq-(b+K_d)\omega-\tau_0-f_\epsilon(\omega),
\]

\[
f_\epsilon(\omega)=
\left(F_c+\Delta F\exp[-(\omega/v_s)^2]\right)
\tanh(\omega/\epsilon),\qquad \epsilon=0.05\;\mathrm{rad/s}.
\]

已发送的实际报文按原数值形成

\[
F_a=K_pq_{ref}+K_d\dot q_{ref}+\tau_{ff}.
\]

未来报文采用连续代理：`r(t)=r_i+(t-t_i)nu_i`，未来强迫项为 `K_p r(t_send)+K_d nu_i`。总线周期为 5 ms，辨识延迟约 3.346 ms。应用时刻固定，强迫项在该时刻切换；延迟小于一个总线周期，因此每段边界最多有一条已发送待生效报文。

这是一项明确的新建模近似：未来量化采用恒等映射，并将静摩擦/库仑切换改为光滑函数。`epsilon` 不是新辨识出的电机参数；不将这个代理称为原混合事件模型的精确等价表达。未来预测中，每个不超过 5 ms 的传播区间使用 10 个 RK4 子步，最大子步 0.5 ms。将关节测量从原时间戳对齐至当前控制时刻时，只使用已经实际发送的报文，采用单独的 `history_rk4_substeps_per_bus=20`，最大子步 0.25 ms。该对齐值是模型传播值，不冒充新的传感器测量。步长减半检验同时将未来 10→20、历史 20→40，并与独立 DOP853 全时间线比较；这项数值验证不替代光滑代理与原事件模型的拟合验收。

末端位置和速度使用非线性几何关系：

\[
p_e=p+R(a,\psi,E)r_b(q),\qquad
v_e=v+R J_b(q)\dot q+\dot Rr_b(q).
\]

`R` 由预测推力方向、偏航及当前姿态残差的衰减模型构造；`r_b` 包含原两连杆几何及安装偏移。该模型保留转动引起的末端位移，但没有显式建立旋翼、整机惯量和关节反作用力矩的全身动力学。这也是后续力矩级全身 NMPC 的独立工作范围。

## 3. 目标函数

以同一原参考轨迹构造末端目标 `p_e*、v_e*` 和名义机体/关节/输入 `p*、q*、u*`。代价为

\[
\min_{x_{0:N},u_{0:N-1}}
\sum_{i=0}^{N-1} h_i\left[
400\|p_{e,i+1}-p^*_{e,i+1}\|^2
+4\|v_{e,i+1}-v^*_{e,i+1}\|^2
+0.25\|p_{i+1}-p^*_{i+1}\|^2
+0.02\|q_{i+1}-q^*_{i+1}\|^2
+0.01\|D_v^{-1}(u_i-u_i^*)\|^2
+0.01\|(h_iD_a)^{-1}(u_i-u_{i-1})\|^2
\right].
\]

`D_v`、`D_a` 分别由配置中的命令速度界、命令变化率界构成对角阵。没有额外终端代价或终端集合；不能由该设计宣称已经证明闭环稳定性或递归可行性。acados 的代价缩放显式设为 1，避免再次乘入已在表达式中的 `h_i`。

`arm_share=0.2` 只用于名义分配参考。最终飞机与关节动作由联合优化产生，不固定为实际 8:2 或 2:8。

## 4. 约束及公共候选验证

优化问题满足初值等式、每段非线性动力学等式，并约束：

1. 五通道命令速度与增量；首段还受真实历史、待生效命令与保护界限制。
2. 积分位置参考、实际关节位置内界，以及光滑传播各应用事件/段末的速度内界 **0.42 / 0.32 rad/s**。
3. 各节点工程制动保护量 `q+rho*dq`，其中 `rho=v_max/(2*a_max)+max_dt+T_hold+source_age`。
4. 姿态映射的向上推力和非奇异航向范围。

不引入松弛变量。用于单侧不等式不存在的一侧的 `1e15` 数值界，双方求解器一致；它没有放宽存在的一侧硬界。

**事件点采样约束并不证明节点间连续安全。**求解完成后，公共原生验证器用原量化与摩擦事件模型独立重放候选，检查完整关节连续包络、各节点实际制动保护量、首条指令 0.16 s 保持及原历史保护。该验证失败的候选不能发布；光滑求解器的“成功”不能替代这一步。

`rho` 是已有控制器的工程保护表达式，命令变化率界不等于已证明的物理最小制动能力。因此这里不附加真机安全不变量或全局递归可行性的声明。

## 5. 求解器及数值核对

acados 使用离散多重打靶、SQP、HPIPM 局部 QP 和 merit backtracking；SQP-RTI 作为同一问题的有限迭代实现单独报告。模型、目标及约束来自同一 CasADi 图。acados 将目标写成 `0.5*yᵀy`、`y=sqrt(2*h)*residual`，采用 Gauss–Newton Hessian 近似；一阶动态与约束导数仍为同图自动微分。这个近似作用于 SQP 子问题，不把原非线性 OCP 改成线性 MPC。IPOPT 参考及独立导数核对仍使用完整图的精确 Hessian。

IPOPT 对同一离散问题采用单重打靶形式作为离线局部参考。单重打靶消去了状态变量，多重打靶保留状态变量；只要满足相同动力学，两者代表相同的有限维控制问题。非凸问题可能有不同局部解，比较目标与约束/KKT 残差，不强行要求控制序列逐位相等，也不把 IPOPT 结果称为已证明的全局最优。

预声明的数值验收包括原始可行性 `2e-7`、控制物理单位下的驻点残差 `2e-3`、互补残差 `2e-5`，以及 AD 中心差分检查。保留独立非负活动乘子拟合；对 IPOPT 内点解另外保存完整有符号对偶，在同一图上独立核算驻点、逐上下界互补性及对偶符号。近活跃集合筛选可能漏掉内点解的小对偶贡献，因此拟合失败与完整对偶核算结果分别保留，不以求解器返回成功代替检查。RTI 返回成功只能表示该次算法调用结束，不能直接等同于完整 NLP 已收敛。

原始 issue 到发布的总时限、求解耗时、候选验证耗时和后处理耗时单独记录；离线求解不伪造在线 deadline。生成的 C 求解器由 C++ 调用，Python 建模与离线核对不在最终在线求解路径内。
